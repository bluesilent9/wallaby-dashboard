# V1 Development Build 20 validation

218 Python regression tests passed, including existing Agent Build 18 contracts. Seventeen JavaScript test programs and all asset syntax checks passed. Build 20 cases cover creator-only workspaces and HTTP guards, concurrent starts, stale draft revisions, saved public drafts, interrupted operation attachment, durable cancellation withdrawal after simulated server interruption, offline delivery, capability gating, exact node/hash receipts, duplicate/late receipts, and returning to an idle builder after every receipt. The transaction creator can coordinate another owner's wallet; that owner cannot access the creator's job and receives no signing-login notice. Late partial signatures cannot revive a cancelled build. Verified broadcast facts remain recorded.

An isolated browser preview verified the initial Start Building a Wallet screen, saved name/policy/signer count after reload, the other-user blocked message, and a cancellation dialog with one received Agent and one offline Agent. After the last simulated receipt, the start screen returned. Screenshot fixtures use simulated users, nodes and public work only; they are review artifacts, not packaged data. No production wallets or nodes were used.

Automatic monitor replication remains blocked while the wallet's creation workspace is active. Unfinished key ceremonies retain expiry/restart reconciliation checks instead of silently regenerating keys. Shared templates, vault estimation, retirement, multisig role visibility, fee rendering, ownership and tax regression coverage remain passing.

The new builder cancellation protocol is Dashboard-side only in this build. Tests simulate the receipt from an Agent's durable local queue; they do not claim that Agent Build 18 implements the new local cleanup UI, backups or deletion. Agents must implement the matching builder_cancellation_v1 contract. Unsupported or disconnected Agents remain pending. Delivery receipt is not approval/deletion confirmation, and cancellation cannot undo broadcast. No private keys, passphrases, production wallet deletion, disc writing or destructive cleanup was performed.

The architecture-all DEB is checked for source parity, excluded runtime records, systemd enable/start packaging, source download and IPv4/IPv6 web/Agent startup. It is not installed here. The previously reported generic Agent getrawmempool failure remains an external Agent investigation; Dashboard does not fabricate pending blocks or add a public fallback.
