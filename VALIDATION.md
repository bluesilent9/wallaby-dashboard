# V1 Build 18 — validation

The full Python regression suite, fourteen JavaScript regression programs and packaged IPv4/IPv6 startup checks are recorded in the build review outputs. New cases cover fresh zero-balance checks across replicas; pending, immature and watch-only funds; incomplete/scanning wallet data; vault-source links; multisig signing accounts; explicit archival/deletion confirmation; all local deletion targets; duplicate requests; wrong-node outcomes; immutable terminal outcomes; cancellation/denial/error warnings; disc confirmation ordering and ownership; validated profile restoration; and sync suppression.

Dashboard makes no mutating Core calls. All deletion is a request for independent local Agent review and Authorise approval. The actual Agent Build 18 validator independently accepts Dashboard-generated version-2 proposals. Earlier archive-only Agents lack the required capability and remain blocked. Holder-group tests cover private plus pure watch-only copies, persisted offline holders, reconnection without duplicate requests, incomplete group gating, descriptor-bound holder detection and withdrawal of queued sync work. Tests use invented wallets and mocked retirement outcomes; no real wallet or archival disc is deleted. Physical deletion, archival history preservation and local approval execution need the matching Agent implementation and its tests.
